# Shared Timeline App PRD

## Product Idea

A private mobile app for couples, friends, families, and groups to track shared memories, places visited, trips, goals, and time spent together.

## Core Users

- Couples
- Best friends
- Friend groups
- Families
- Travel groups

## Core Concept

The app is organized around circles.

A circle is a private shared space between two or more people.

Each circle can have:

- memories
- timeline events
- places visited
- trips
- shared goals
- bucket list items
- stats

## MVP Features

- User registration and login
- Create a circle
- Invite people to a circle
- View a circle dashboard
- Add memories to a shared timeline
- Add dates to memories
- Add notes/descriptions to memories
- Add optional locations to memories
- View places visited
- Add shared goals or bucket list items
- Mark goals complete
- Show simple stats:
  - days since circle started
  - number of memories
  - number of places
  - number of completed goals
