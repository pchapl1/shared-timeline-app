# Backend Setup Plan

## Goal

Build a Django + DRF API for the Shared Timeline App.

## Backend Apps

- accounts
- circles
- memories
- places
- goals
- trips

## Setup Steps

1. Create Django project
2. Install Django REST Framework
3. Connect PostgreSQL
4. Create backend apps
5. Create models
6. Create serializers
7. Create API views
8. Create URLs/routes
9. Add authentication
10. Add tests
