# Architecture

## Tech Stack

### Frontend
- React Native
- Expo
- TypeScript

### Backend
- Django
- Django REST Framework
- PostgreSQL

## App Structure

The app is centered around circles.

A circle is a private shared space for:
- a couple
- friends
- a group
- a family
- a travel group

## Main Backend Apps

- accounts
- circles
- memories
- places
- goals
- trips

## Main Frontend Areas

- authentication
- circle dashboard
- timeline
- memories
- places/map
- goals/bucket list
- profile/settings

## Core Flow

1. User creates an account
2. User creates or joins a circle
3. User opens a circle dashboard
4. User adds memories, places, and goals
5. The app shows a shared timeline and stats
